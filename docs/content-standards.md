# GuideHollow Sheets content standards

Write for a reader solving a specific spreadsheet task. Start with the actionable answer. Use one H1 supplied by the page template; article bodies begin with prose and H2 sections. Keep native formulas copyable, range endpoints aligned, and identifiers distinct from numerical measures.

Every guide needs an original small fixture with its cell layout, expected outputs, at least one rejected or boundary case, an error/cause/remedy explanation, and applicable product/version/locale limits. Link a downloadable CSV/TXT/JSON where it adds reproducibility. Synthetic records must not imply real customers, experiments, or author credentials.

Use primary Microsoft and Google documentation for syntax and version claims. Read the cited page and record retrieval date. Keep citations near the claims. No fabricated app execution, screenshots, expertise, user results, benchmarks, citations, prices, traffic, or revenue. Never equate submission with indexing or a local route with publication.

Verification has separate layers: (1) source documentation, (2) JavaScript mathematical/raw-text oracle, (3) execution in each native application, (4) render and download checks, (5) production verification. Passing one does not pass the others. Record edition, platform, locale, timezone if relevant, formula, and observed output for any native test. An oracle is not a general spreadsheet evaluator.

Date tutorials must distinguish strings from real date/time values, avoid ambiguous locale parsing, and use exclusive next-period boundaries for timestamp intervals. CSV guides preserve leading-zero, long, and exponent-like IDs as text; display padding cannot restore an unknown original. Duplicate guides state key columns, normalization, comparison, and survivor rules, preserve the source, and distinguish exact raw strings from application comparison behavior.

Each guide includes a quality learning report with the eight required headings: search intent; sources/date/claims; distinct contribution; prior lessons applied; corrections; unverified; postpublication URL currently pending; next improvements. Apply both lessons: no fake app test, and original recheckable inputs/results. Draft status and public readiness are editorial decisions, not a claim of AdSense acceptance or search indexing.

Internal links must resolve to a real planned guide or tool route and use descriptive anchor text. No keyword/word-count padding or stock imagery merely to fill a quota. Scope remains the six initial guides and their reproducible assets. Correct factual mistakes before expanding coverage.
